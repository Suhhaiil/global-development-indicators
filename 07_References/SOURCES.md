# Data Sources and References

This project uses data from the World Bank's World Development Indicators (WDI) database.

## Main Database

- **World Development Indicators:** https://databank.worldbank.org/source/world-development-indicators

## Indicators

1. **GDP per capita (current US$)**  
   https://data.worldbank.org/indicator/NY.GDP.PCAP.CD

2. **Inflation, consumer prices (annual %)**  
   https://data.worldbank.org/indicator/FP.CPI.TOTL.ZG

3. **Unemployment, total (% of total labour force) (modelled ILO estimate)**  
   https://data.worldbank.org/indicator/SL.UEM.TOTL.ZS

4. **Population, total**  
   https://data.worldbank.org/indicator/SP.POP.TOTL

## Coverage

- Countries: 15 selected economies
- Period: 2000–2024
- Observations: 375 country-year records

## Note

The analysis uses the indicators as reported in the World Bank database. GDP per capita is measured in current US dollars and is not adjusted for inflation or purchasing-power differences.
